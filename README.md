#  Task Management App

A simple and interactive Task Management Application built using HTML, CSS, and Vanilla JavaScript.

This application allows users to manage their daily tasks by adding, editing, deleting, and marking tasks as completed. All tasks are saved in the browser's Local Storage, so data persists even after refreshing the page.

# Features

- **Add Tasks:** Create new tasks with their creation date.
- **Display Tasks:** View all saved tasks.
- **Edit Tasks:** Update existing task titles.
- **Delete Tasks:** Remove tasks with a confirmation message.
- **Complete Tasks:** Mark tasks as completed or switch them back to pending.
- **Local Storage:** Automatically save tasks in the browser to preserve data after refreshing the page.
- **Current Date:** Automatically assign the current date when creating a new task.
- **Interactive UI:** Simple interface with action buttons and Material Symbols icons.

# Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- Browser Local Storage
- Google Material Symbols

 Data Storage

The application uses the browser's `localStorage` to store tasks.

Each task contains:

- `title`: The task name.
- `date`: The task creation date.
- `isdone`: A boolean value indicating whether the task is completed.
